## Dataset Documentation

"completed_records_plus_sentiment_metrics.csv"

This directory contains the prepared dataset used in the Video Game Commercial Performance Analysis project.

The dataset combines video game records with additional measurements related to commercial performance, gameplay, ratings, and review sentiment.

## Purpose

The dataset supports exploratory analysis of relationships between video game sales, game characteristics, critic and user reception, and sentiment-related metrics.

## Dataset Overview

- File: "completed_records_plus_sentiment_metrics.csv"
- Format: CSV (Comma-Separated Values)
- Reported size: Approximately 3,002 game records and 45 variables; verify against the current file.
- Role: Primary input for the project's analysis notebook.

## Data Categories

Depending on the available columns, the dataset may include:

- Game and platform identifiers.
- Commercial performance and sales measurements.
- Genre and other descriptive attributes.
- Critic and user ratings.
- Gameplay-related measurements.
- Sentiment metrics derived from review data.

## Data Processing

The file is a prepared dataset. Consult the analysis notebook to understand how it is loaded, filtered, transformed, and used to generate the reported results.

The original sources, units, missing-value conventions, and sentiment aggregation procedures should be documented alongside the corresponding fields.

## Important Notes

- Sentiment metrics are analytical measurements and should not be treated as direct measures of commercial success.
- Relationships between sentiment, ratings, and sales do not necessarily imply causation.
- Check the notebook for the exact source datasets and preprocessing steps.
